# CompetitecaTCC
Trabralho de Conclusão de Curso desenvolvido pelos Técnicos em Informática Pedro Beber de Queiroz Vidal e Gustavo Henrique de Souza Oliveira

## Overview
Competiteca is a web system for organizing sports competitions, built as the final project of the Technical Computing course at IFPR (Irati campus).

- **Stack:** Java (JSP/Servlets) web application, Hibernate for persistence (`hibernate.cfg.xml`), DAO pattern, NetBeans/Ant project.
- **What it does:** registration of administrators and participants, athletes, teams, venues and competitions; solo and team (collective) modalities; knockout blocks and round-robin ("todos contra todos") match tables; team entry requests exchanged through an internal message inbox.
- **Layout:** `src/java/.../modelo` (entities), `src/java/.../dao` (data access), `web/` (JSP pages, CSS, images).
